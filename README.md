# Bank-Loan-Analysis-Dashboard
Built a Bank Loan Analysis dashboard in Microsoft Excel to track loan applications, funded amount, repayments, defaults, and customer segments. Cleaned data, used Pivot Tables, formulas, charts, and slicers to create KPIs and identify approval trends, risk patterns, and portfolio performance for better lending decisions. The project transforms raw loan records into meaningful insights through data visualization and KPI reporting.

## Objectives
- Track loan applications and funded amounts  
- Monitor repayments and defaults  
- Analyze customer segments  
- Identify approval and rejection trends  
- Support smarter lending decisions  

## Tools & Techniques
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  
- Formulas  
- Data Cleaning  

## Key Metrics
- Total Loan Applications  
- Funded Amount  
- Amount Repaid  
- Default Rate  
- Approval Rate  
- Customer Segment Analysis  

## Dashboard Features
- Interactive filters using slicers  
- KPI summary cards  
- Monthly loan trend analysis  
- Customer category breakdown  
- Loan status comparison  
- Clean and user-friendly dashboard design  

## Key Insights
- Identified high-performing customer segments  
- Tracked repayment and default behavior  
- Observed trends in approvals and rejections  
- Measured overall loan portfolio performance  

## Challenges Addressed
- Cleaned inconsistent loan records  
- Structured raw data for reporting  
- Built dynamic KPIs with formulas  
- Improved dashboard accuracy and usability
